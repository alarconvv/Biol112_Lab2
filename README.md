# Koi Fish Mendelian Genetics Simulator
An interactive R Shiny application designed for biology and genetics lab courses. This tool replaces manual coin flipping in Hardy-Weinberg Equilibrium (HWE) and Mendelian inheritance simulations, allowing students to focus on physical bead sampling, cross analysis, and population statistics.

## Prerequisites
Ensure you have R (version 4.0.0 or higher recommended) and RStudio installed on your system.

Required R Packages

install.packages(c("shiny", "bslib", "DT"))


# Quick Start

- Open RStudio.

- Create a new script file named app.R and paste the full Shiny application code into it.

- Click the Run App button in the top right corner of the RStudio script editor.

  Alternatively, execute the following command in your R console:
  
  shiny::runApp("path/to/app.R")
